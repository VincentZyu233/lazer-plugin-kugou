# 🧪 酷狗音乐插件 (lazer.kugou) 黑盒测试指引

本指引基于真实用户使用动线（启动登录 → 主页探索 → 搜索找歌 → 歌手/专辑详情 → 播放与歌词收藏），统一按标准表格梳理端到端验证用例。

---

## 🔑 一、启动与账号会话 (Account & Session)

| 测试项 | 操作路径 | 宿主契约 | 预期结果 |
| :--- | :--- | :--- | :--- |
| **会话无感唤醒** | 打开 Lazer 播放器 | `checkSession` | 左下角自动恢复用户头像、昵称 `VincentZyu` 与普通账户标识 |
| **多端资料热同步** | 手机端修改昵称/头像后刷新会话 | `/v7/get_all_list` | 插件静默拉取最新云端资料并写回本地缓存，界面即时对齐 |
| **双重登录授权** | 退出登录后选择扫码或验证码 | `qrKey` / `loginCaptcha` | 扫码授权或输入短信验证码后成功签发 Token 登录 |

## 📻 二、主页快捷推荐与电台 (Home Feed & Radio)

| 测试项 | 操作路径 | 宿主契约 | 预期结果 |
| :--- | :--- | :--- | :--- |
| **今日限定好歌** | 主页点击顶部卡片 #1 | `onDaily` / `homeFeed.daily` | 拉取酷狗日推算法并展示 30 首私人专属虚拟推荐歌单 |
| **私人漫游电台** | 主页点击顶部 #2 或电台 #1 | `onFm` / `radio.personal` | 进入 FM 漫游模式，切歌与播放时连续流式预加载 |
| **心动模式电台** | 主页点击顶部 #3 或电台 #3 | `onHeart` / `radio.heart` | 调取风格雷达，推荐并播放偏好契合曲目 |
| **反复聆听回放** | 主页点击顶部卡片 #4 | `onReplay` / `playQueue.recent` | **本地闭环**：无需外部请求，直接循环播放最近播放记录 |
| **红心随机起播** | 主页点击电台专栏 #2 | `onLiked` / `collections.liked` | 获取云端红心收藏列表，Fisher-Yates 打乱后连续起播 |
| **歌手专属电台** | 底栏正在播放时点击电台 #4 | `onArtist` / `radio.artist` | 提取当前播放歌手，自动生成专属曲风电台流 |

## 🔍 三、综合搜索找歌 (Search Page)

| 测试项 | 操作路径 | 宿主契约 | 预期结果 |
| :--- | :--- | :--- | :--- |

## 🎤 四、歌手主页深入交互 (Artist Page)

| 测试项 | 操作路径 | 宿主契约 | 预期结果 |
| :--- | :--- | :--- | :--- |
| **歌手一键起播** | 歌手详情页点击红色【▶ 播放】 | `playQueue(artist)` | 将热门歌曲载入播放队列并立即自首曲起播 |
| **热门歌曲全部展开** | 点击歌曲排行右侧【查看全部 >】 | `AppArtistSongsPage` | 进入全量单曲列表，支持向下滚动分页加载 |
| **单曲 / EP 专辑进入** | 点击下方单曲/EP 封面（如《わたしのヘリテージ》） | `openAlbumDetails` | 无缝跳转至对应专辑详情页，展示封面与曲目信息 |
| **发行专辑全部展开** | 点击单曲/EP 右侧【查看全部 >】 | `AppArtistReleasesPage` | 展开歌手发布的所有历史专辑与 EP 列表 |
| **单曲右键菜单** | 点击任一单曲条目右侧的【···】 | 上下文菜单弹窗 | 弹出菜单，支持下一首播放、添加到歌单、查看专辑等 |

## 💿 五、专辑详情页 (Album Page)

| 测试项 | 操作路径 | 宿主契约 | 预期结果 |
| :--- | :--- | :--- | :--- |
| **专辑元数据展现** | 进入任意专辑详情页 | `album(id)` | 验证大图封面、发行年份、歌手名与曲目数量准确无误 |
| **专辑整张起播** | 点击顶部【播放】/【随机播放】 | `playQueue(album)` | 将整张专辑曲目按顺序或随机灌入播放队列起播 |
| **专辑单曲跳转** | 点击专辑列表内的任意单曲 | `song(id)` | 正确解析该曲目音频流并在底栏正常播放 |

## 🎵 六、全屏播放与动态歌词 (Now Playing & Lyrics)

| 测试项 | 操作路径 | 宿主契约 | 预期结果 |
| :--- | :--- | :--- | :--- |
| **逐行动态歌词** | 底栏点击封面拉起全屏大卡片 | `lyrics(id)` | 歌词随时间轴平滑滚动并高亮当前播放句 |
| **歌词点击快进** | 点击任意未播放歌词行 | `seek(timestamp)` | 播放器精准跳转至该歌词对应的时间戳起播 |
| **多音质无缝降级** | 切换标准/HQ(320k)/无损(FLAC) | `stream(id, quality)` | 动态解析对应码率音源，切换平滑无卡顿 |
| **红心收藏联动** | 点击播放界面红心收藏图标 | `setFavorite(id)` | 收藏状态即时更新，左侧【VincentZyu喜欢的音乐】计数实时 +1 |
