## 一、 背景与调研概述

`lazer-plugin-kugou` 当前已实现基础但核心的闭环功能：
- **搜索**（单曲、歌单、歌手）；
- **音频流**（128k、320k、FLAC 音质）；
- **基础歌词**（标准单行 LRC）；
- **歌单与收藏**（我喜欢同步、私人歌单与公共特辑）；
- **双模登录**（Web 二维码扫码与移动端短信验证码握手登录）；
- **推荐流**（私人漫游电台与推荐歌单）。

通过深入调研本地成熟的 `KugouMusic.NET` 源码（涵盖 `SongClient`、`LyricClient`、`RecommendClient`、`RankClient`、`CommentClient`、`UserClient` 等多个模块的底层 Raw API），我们发现酷狗服务端不仅提供了基础的媒体拉取能力，还沉淀了大量**极具差异化竞争力**的特色接口（如逐字动感歌词、副歌高潮起止点、全量官方排行榜、歌手高清壁纸、试听降级保护等）。

## 二、 核心体验改善点（Quick Wins）

### 2.1 歌词双语翻译支持（低成本，高回报）

#### 现状与痛点
当前 `kg/catalog.lua` 中的 `catalog.lyrics` 仅下载了 `fmt = "lrc"`，只解码了返回体中的 `content` 字段。遇到日韩欧美外文歌曲时，无法展示中文翻译歌词。

#### 协议参考 (`KuGou.Net/Clients/LyricClient.cs`)
酷狗的 `/download` 歌词接口在返回原歌词 `content`（Base64）的同时，若存在官方或 UGC 翻译，会在同一 JSON 中返回 `trans`（Base64 编码的 UTF-8 翻译 LRC 文本）：
```csharp
if (json.TryGetProperty("trans", out var transElem) && transElem.ValueKind == JsonValueKind.String)
{
    decodedTrans = Encoding.UTF8.GetString(Convert.FromBase64String(transElem.GetString()!));
}
```

#### 改善落地方案
在 `kg/catalog.lua` 的 `catalog.lyrics` 中：
1. 检查 `downloadRes.trans` 是否存在且非空；
2. 若存在，直接使用插件已有的 `crypto.base64_decode(downloadRes.trans)` 解码；
3. 将翻译行解析并挂载在返回结果的 `translation` 字段中，供 Lazer 歌词视图渲染双语歌词。

### 2.2 VIP 歌曲平滑降级与试听保护（`freePart` 机制）

#### 现状与痛点
当未开通酷狗 VIP 的用户点播版权保护曲目时，请求 `flac` 或 `320k` 会收到服务端 `status = 0` 或空 URL，导致插件返回 `nil`，Lazer 播放列表报红跳歌。

#### 协议参考 (`KuGou.Net/Clients/SongClient.cs`)
在酷狗播放链接接口中：
- 传递 `freePart = true` 参数，允许在用户无完整版权时，拉取 30~60 秒的高品质试听片段；
- 采用多档位递减策略：`flac` 失败则降级到 `320k`，再失败降级到 `128k`，最后尝试 `freePart`。

#### 改善落地方案
在 `kg/catalog.lua` 的 `catalog.stream` 中构建梯级容错重试机制：
```lua
-- 伪代码设计
local qualities = { args.quality or "flac", "320", "128" }
for _, q in ipairs(qualities) do
  local url = tryFetchUrl(hash, q, false)
  if url then return { url = url, ... } end
end
-- 若完整播放无权限，尝试拉取官方试听流
local freeUrl = tryFetchUrl(hash, "128", true)
if freeUrl then
  return { url = freeUrl, isPreview = true, ... }
end
```

### 2.3 补全评论区支持（实现 manifest 声明的契约）

#### 现状与痛点
插件 `manifest.json` 中声明了 `"comments"` 能力，但 `main.lua` 缺少 `operation == "comments"` 的分发，用户在 Lazer 中查看酷狗歌曲评论时提示不支持。

#### 协议参考 (`KuGou.Net/Clients/CommentClient.cs`)
- 接口地址：`http://comment.service.kugou.com/v1/get_comment_list`
- 核心参数：
  - `mixsongid`（可从搜索结果或 `kmr` 接口直接获取）；
  - `page`、`pagesize`；
  - `code=fc4be23b4e972d07f2b7d89f388030c2`。
- 返回数据结构直接包含热评（`hot_list`）与最新评论（`list`），包含用户头像、昵称、点赞数与评论发表时间。

#### 改善落地方案
1. 在 `kg/catalog.lua` 新增 `catalog.comments(args)`；
2. 映射酷狗评论模型至 Lazer 通用 Comment 结构（`id`, `user`, `content`, `likeCount`, `createdAt`）；
3. 在 `main.lua` 暴露 `operation == "comments"` 分发分支。

## 三、 差异化新功能潜力（Major Enhancements）

### 3.1 逐字动感歌词（KRC）原生解密

#### 功能潜力
酷狗拥有全网最精确的逐字毫秒级动感打点歌词（`.krc` 格式），若能将其接入，可让 Lazer 展现媲美酷狗原生的 Apple Music 级逐字动态流光与卡拉 OK 动感歌词。

#### 逆向算法解析 (`KuGou.Net/util/KGCrypto.cs`)
KRC 歌词解密过程非常轻量，纯算法逻辑如下：
1. **魔数检测**：跳过前 4 字节魔数识别头 `@Gaw`；
2. **XOR 异或解密**：使用固定的 16 字节密钥循环异或：
   ```csharp
   byte[] enKey = [64, 71, 97, 119, 94, 50, 116, 71, 81, 54, 49, 45, 206, 210, 110, 105];
   for (var i = 4; i < bytes.Length; i++) {
       bytes[i] = (byte)(bytes[i] ^ enKey[(i - 4) % enKey.Length]);
   }
   ```
3. **ZLib 解压**：对解密后的字节流执行标准 zlib 膨胀解压，即可得到纯文本打点标签：
   `[1250,3800]<0,450,0>听<450,600,0>见<1050,800,0>冬<1850,900,0>天...`

### 3.2 酷狗官方全量排行榜（Top500 / 飙升榜 / 电音榜）

#### 功能潜力
酷狗 TOP500 与飙升榜是国内最知名的音乐风向标之一。目前插件主页仅有推荐歌单与私人漫游，接入排行榜后可直接在 Lazer 发现页的「排行榜 / 榜单」板块呈现。

#### 协议参考 (`KuGou.Net/Clients/RankClient.cs`)
1. **全量榜单索引**：
   - 接口：`GET /v3/rank/list`（`host = "mobilecdn.kugou.com"`）
   - 参数：`withsong=1`（附带榜单前 3 首歌曲预览信息与封面）
2. **榜单曲目明细**：
   - 接口：`GET /v3/rank/audio`
   - 参数：`rankid`、`page`、`pagesize`

---

### 3.3 歌曲副歌/高潮片段识别（Climax Timestamp）

#### 功能潜力
酷狗服务端提供了专门的 `/v1/climax` 接口，自动标记歌曲中最具代表性的高潮/副歌区间。
- **应用场景**：
  - 切歌时智能淡入至副歌；
  - 列表快速滑动试听模式（只播放 20 秒高潮部分）；
  - 歌词时间轴高潮区间微光动效。

#### 协议参考 (`KuGou.Net/Protocol/Raw/RawSongApi.cs`)
- 接口地址：`POST http://gateway.kugou.com/v1/climax`
- 传入 `hash`，返回 JSON 包含 `start_time`（毫秒）与 `duration`（时长）。

---

### 3.4 歌手高清写真背景轮播（Audio Images）

#### 功能潜力
酷狗曲库为每一首经典歌曲和歌手维护了最多 5 张高清官方写真壁纸（`GetAudioImagesAsync`）。
- **应用场景**：
  - 在 Lazer 播放全屏界面中，可作为唱片背景的高清轮播图；
  - 极大提升桌面端与大屏 TV 端的视觉沉浸感。

---

### 3.5 用户 VIP 详情精细化展示

#### 现状
插件目前在 `session` 接口中仅解析了基本昵称与头像，VIP 标签相对简略。

#### 协议参考 (`KuGou.Net/Clients/UserClient.cs`)
调用 `/v1/vip/user_detail` 可以精准解析出：
- `vip_type`（0: 普通, 1: 音乐包, 6: 豪华 VIP, 7: 超级 VIP）；
- `is_vip`；
- `due_date`（到期时间戳）。
可以在 Lazer 侧边栏和设置页中准确展示用户真实的会员特权状态与有效期。
