## 🌟 第一梯队 (T1)：核心高感知与基础体验突破

本梯队聚焦于**免 VIP 账号也能立即获得巨大体验提升**的核心高频场景（歌词体验、歌曲探索、社区互动）。

### 1.1 歌词双语翻译支持（即刻收益，极低成本）

- **现状痛点**：当前 `catalog.lyrics` 仅拉取 `fmt = "lrc"`，遇到日文、韩文、英文等外文歌曲时无法显示中文译文。
- **协议参考 (`KuGou.Net/Clients/LyricClient.cs`)**：
  酷狗官方 `/download` 接口不仅返回原歌词 `content`（Base64），当存在翻译时，同层 JSON 会直接下发 `trans` 字段（Base64 编码的 UTF-8 翻译 LRC）。
  ```csharp
  if (json.TryGetProperty("trans", out var transElem) && transElem.ValueKind == JsonValueKind.String)
  {
      decodedTrans = Encoding.UTF8.GetString(Convert.FromBase64String(transElem.GetString()!));
  }
  ```
- **落地改动**：在 `kg/catalog.lua:catalog.lyrics` 中：
  1. 检测 `downloadRes.trans` 是否存在；
  2. 若存在，使用插件已有的 `crypto.base64_decode(downloadRes.trans)` 解码；
  3. 将翻译行组装并写入返回体，Lazer 原生即可无缝渲染上下双语歌词。

---

### 1.2 逐字动感歌词（KRC 原生解密）

- **现状痛点**：当前仅支持整句滚动的标准 LRC。酷狗最具核心竞争力的功能就是逐字精准高亮的动感歌词。
- **协议参考 (`KuGou.Net/Utils/KGCrypto.cs`)**：
  酷狗 KRC 格式属于标准对称加密容器：
  1. 头部 4 字节魔数：`@Gaw`（ASCII `[0x40, 0x47, 0x61, 0x77]`）；
  2. 密钥（16 字节固定 XOR Mask）：
     ```csharp
     private static readonly byte[] KrcKey = [
         64, 71, 97, 119, 94, 50, 116, 71, 81, 54, 49, 45, 206, 210, 110, 105
     ];
     ```
  3. 算法：跳过前 4 字节，对后续字节逐字节循环 XOR，解密后使用标准 zlib inflate 解压缩，得到包含每个字毫秒偏移的 KRC 文本（如 `[1200,350]<0,50,0>听<50,100,0>见<150,200,0>你`）。
- **落地改动**：
  在 `kg/crypto.lua` 中封装纯 Lua 的 XOR 解密与 Zlib 展开工具，或由插件输出带有逐字打点信息的扩展歌词格式供 Lazer 渲染。

---

### 1.3 酷狗官方全量榜单（Top500 / 飙升榜 / 新歌榜）

- **现状痛点**：目前主页除了私人漫游和搜索，缺乏全局官方公信力榜单，难以快速发现热门新歌与经典好歌。
- **协议参考 (`KuGou.Net/Clients/RankClient.cs`)**：
  酷狗具有极其丰富成熟的排行榜接口体系，免登录即可畅享全量热门：
  - **榜单目录拉取**：
    `http://mobilecdnbj.kugou.com/api/v3/rank/list?version=9108&plat=0&showtype=2`
  - **榜单歌曲明细**：
    `http://mobilecdnbj.kugou.com/api/v3/rank/audio?version=9108&rankid={rankid}&page={page}&pagesize={pagesize}`
- **落地改动**：
  在 `kg/catalog.lua` 暴露 `catalog.ranks()`，支持 Top500、飙升榜、华语新歌榜等热门大榜一键拉取与分页浏览。

---

### 1.4 补全评论区支持（实现 manifest 声明的契约）

- **现状痛点**：`manifest.json` 中已声明 `"comments"` 能力，但 `main.lua` 缺少 `operation == "comments"` 分发逻辑，导致 Lazer 点击歌曲评论时报错。
- **协议参考 (`KuGou.Net/Clients/CommentClient.cs`)**：
  - 接口：`http://comment.service.kugou.com/v1/get_comment_list`
  - 核心参数：`mixsongid`（可从搜索结果、播放详情中直接提取）、`page`、`pagesize`。
- **落地改动**：
  在 `kg/catalog.lua` 中补充 `catalog.comments(args)`，支持拉取热评（置顶神评）与最新发表的评论，补齐扩展协议契约。

## 🎨 第二梯队 (T2)：视听增强与探索拓展

本梯队聚焦于**视觉质感与选歌听歌场景的深度拓展**。

### 2.1 副歌高潮识别与起止点打点（Climax）

- **功能价值**：支持在进度条上标注副歌（高潮）区间，或用于 15 秒快速切歌试听。
- **协议参考 (`KuGou.Net/Clients/SongClient.cs`)**：
  - 接口：`http://m.kugou.com/app/i/getSongInfo.php?cmd=playInfo&hash={hash}` 或 `http://serviceinfo.kugou.com/v1/climax?hash={hash}`
  - 返回体包含：
    - `start`: 副歌开始时间（毫秒）；
    - `end` / `duration`: 副歌持续时间。
- **落地改动**：在播放详情元数据中附带 `climax: { start: ms, end: ms }`，宿主支持时可在进度条高亮高潮区间。

---

### 2.2 歌手高清写真背景轮播（Audio Images）

- **功能价值**：替换当前单一、易拉伸的单曲封面，在播放页提供沉浸式的多张高清歌手现场与写真大图轮播背景。
- **协议参考 (`KuGou.Net/Clients/SongClient.cs`)**：
  - 接口：`http://serviceinfo.kugou.com/v1/audio_images?hash={hash}`
  - 返回包含 3~8 张高分辨率歌手摄影背景 URL 数组。
- **落地改动**：在 `catalog.track` 元数据中下发 `backgrounds: [...]`。

---

### 2.3 智能推荐流与单曲雷达拓展

- **功能价值**：当前已支持公共漫游，但缺乏“从某首歌出发一键漫游（单曲雷达）”的能力。
- **协议参考 (`KuGou.Net/Clients/RecommendClient.cs`)**：
  - 类似歌曲拉取：`GetSimilarSongsAsync(hash)`；
  - 风格流派雷达：基于标签算法生成相似单曲队列。
- **落地改动**：在单曲操作菜单中注入“以此单曲生成雷达”的漫游上下文。

## 🛡️ 第三梯队 (T3)：VIP 增值与账号容错处理（后备）

因为日常不依赖 VIP 账号，本梯队特性作为**兜底保护机制与信息辅助**，优先级排在最后。

### 3.1 VIP 歌曲平滑降级与试听保护（`freePart` 机制）

- **功能价值**：当非 VIP 用户在排行榜或搜索中点播到 VIP 专享歌曲时，防止直接报红切歌，而是友好拉取官方 30~60 秒试听分片。
- **协议参考 (`KuGou.Net/Clients/SongClient.cs`)**：
  - 参数：在拉取 URL 时若 `status == 0`，附带 `freePart = true` 再次请求；
  - 策略：`flac` -> `320k` -> `128k` -> `freePart` 试听片段。
- **落地改动**：仅作为播放失败时的底层兜底重试逻辑，保证播放器不因版权中断跳红。

---

### 3.2 VIP 会员状态精细化展示

- **功能价值**：仅供账号主页或设置页清晰展示当前登录账号状态（普通用户 / 音乐包 / 豪华 VIP / 到期天数）。
- **协议参考 (`KuGou.Net/Clients/UserClient.cs`)**：
  - 接口：`GetUserInfoAsync(userId, token)`，从 JSON 中解析 `vip_type`、`vip_end_time`。
- **落地改动**：在用户登录成功后的个人资料卡片中做只读展示。
