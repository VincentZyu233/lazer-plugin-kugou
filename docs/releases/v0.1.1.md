# Lazer 酷狗音乐插件 v0.1.1

### 亮点更新
1. **重构短信验证码登录握手加密协议（对标 KugouMusic.NET 4.2.2+）**
   - 彻底修复手机短信验证码登录时服务端报“登录失败，请稍后再试”的缺陷。
   - 引入动态 AES-256-CBC 密钥派生机制，对手机号与验证码载荷（`params`）实施标准对称加密。
   - 引入酷狗移动端 Lite RSA 1024-bit 无填充模幂加密，安全封包密钥凭据（`pk`）。
   - 补齐移动端 `t1`（时间戳加密）与 `t2`（设备序列指纹 `installGuid|hash|mac|dev|time` 加密）安全校验项。
   - 对手机号实施标准掩码脱敏（`17*****0`），计算专用登录签名 `key = CalcLoginKey(timeMs)`。
   - 请求重定向至高容灾登录端点 `loginserviceretry.kugou.com`，注入 `support-calm: 1` 与 `x-router: login.user.kugou.com`。
   - 自动截获服务端返回的 `res.data.secu_params` 密文并使用动态密钥解密还原真实 `userid`、`token`、`nickname` 等凭据。

2. **设备指纹自举生成与持久化**
   - 自动为客户端自举生成幂等的 `installGuid`、`installMac` 与 `installDev`，并安全持久化至 Lazer 隔离存储，防止频繁换设备触发酷狗安全风控。
