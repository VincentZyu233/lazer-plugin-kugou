# Lazer 酷狗音乐插件 v0.1.2

### 亮点修复与协议对齐
1. **彻底解决短信验证码登录报 `error_code: 20006`（签名/校验参数错误）问题**
   - **RSA 无填充大数模幂（Raw RSA）128 字节零填充对齐**：酷狗原生 RSA-1024 密钥要求将 UTF-8 载荷拷入 128 字节缓冲区前部，其余低位补 `0x00` 字节（256 位 Hex 串）。修复了此前未补零导致 `pk` 加密密文完全不匹配、服务端解密失败的硬核缺陷。
   - **设备识别指纹 `installDev` 规格对齐**：生成规则调整为酷狗官方标准的 16 位大写英文字母与数字组合（`0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ`）。
   - **补充酷狗专用请求头**：请求全面注入 `kg-rf: B9EDA08A64250DEFFBCADDEE00F8F25F`、`kg-thash: 5d816a0` 与 `kg-rec: 1`。
   - **动态修正 `uuid` 计算公式**：默认公共参数与接口统一使用 `md5(dfid .. mid)` 动态计算 `uuid`，防止老旧写死值导致服务端防刷拦截。
   - **增强网络与登录调试日志**：登录异常时自动将服务端原始返回记入持久化日志，便于排查定位。
