# Lazer 酷狗音乐插件 v0.1.3

### 核心异常修复
1. **彻底修复 Dart 运行时 `TypeError: type 'double' is not a subtype of type 'int?'` 导致的登录闪退**
   - Lazer 的 Dart 宿主在处理 `rsa_modpow` 时，`spec['exponent'] as int?` 会将 Lua number 传入的浮点值（如 `65537.0`）判定为非 int 并直接抛出异常中断。
   - 本次移除 Lua 显式传入的数字类型 `exponent` 与 `width`，交由 Dart 宿主使用安全的默认值（`65537` 与 `256`），彻底杜绝跨语言类型转换异常。

2. **全局异常保护与登录链路调试日志追踪**
   - 在 `main.lua` 对 `loginCaptcha` 与 `sendCaptcha` 增加全局 `pcall` 防御。
   - 增加详尽的登录全生命周期 `debugLog`，确保任何偶发异常均能精准捕获。
