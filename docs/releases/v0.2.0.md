# Lazer 酷狗音乐插件 v0.2.0

### 重大里程碑更新
1. **KRC 逐字动感歌词与毫秒级高亮渲染**
   - 全面支持酷狗官方 KRC 动感歌词格式，经宿主轻量扩展高效解密并转换为 Lazer 标准 YRC 逐字高亮协议。
   - 彻底优化逐字时间轴对齐，支持极速节奏、超长拖音与复杂外语词组的毫秒级平滑跟随。

2. **纯净双语中文翻译与 1:1 精确行对齐**
   - 深度解析酷狗内嵌多语言语言包（`[language:]`）并自动提取中文翻译。
   - 专一化纯中文副行策略，与原文 1:1 绝对行匹配，杜绝罗马音穿插与双语池竞态混杂。

3. **歌曲热门与最新评论区生态对接**
   - 全面支持歌曲评论拉取，包含精选/热门/最新评论流、用户头像、发表时间与点赞数。
   - 彻底解决 Dart 虚拟机 `lua_dardo_plus` 正则模式捕获限制，确保 140+ FPS 丝滑浏览。

4. **手机验证码与二维码双轨登录全链路打通**
   - 修复 SMS 短信验证码登录协议中的核心参数与签名缺陷，实现完整的登录态持久化。

5. **极简瘦身与 Dart 沙箱底层兼容重构**
   - 剔除 500+ 行死代码与纯 Lua inflate 冗余，插件包体积大幅瘦身 60% 以上。
   - 消除歌词拉取异常误吞导致的“永久纯音乐”错误缓存，增强整体稳定性与可重试能力。
